## 1. 产品概述

面向维修质量部门的数据驱动型航线排故知识库看板，旨在通过数据洞察发现可靠故障经验与低效排故路径，推动航线维修改进。产品为质控人员提供故障热力分析、案例质量评估和每周复盘管理三大核心功能，让知识库从查询工具升级为质量改进驱动引擎。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 质控人员 | 多维度筛选故障、查看案例质量、管理复盘任务、指定责任工程师 |

### 2.2 功能模块

1. **故障热力页**：多维度筛选、故障分布热力、关键指标统计、故障详情列表
2. **案例质量页**：知识条目引用分析、低成功率条目识别、案例完整性检查
3. **复盘清单页**：高频重复故障列表、超时排故记录、复盘任务管理、改进跟踪

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 故障热力页 | 筛选器 | 机型、基地、ATA章节、季节、故障代码多维度筛选 |
| 故障热力页 | 指标概览 | 故障次数、平均停场时间、重复飞机数、常用动作排行 |
| 故障热力页 | 热力分布 | ATA章节×月份热力图可视化 |
| 故障热力页 | 故障列表 | 故障明细、停场时长、重复标记、处理动作 |
| 案例质量页 | 引用分析 | 知识条目引用频次与成功率散点分布 |
| 案例质量页 | 低质条目 | 频繁引用但成功率低的知识条目警示 |
| 案例质量页 | 完整性检查 | 缺少手册依据、放行结论、后续跟踪的案例清单 |
| 复盘清单页 | 高频故障 | 自动列出本周高频重复故障 |
| 复盘清单页 | 超时记录 | 排故超时案例及超时分析 |
| 复盘清单页 | 任务分派 | 指定责任工程师、补充原因分析、修订排故提示 |
| 复盘清单页 | 培训提醒 | 发起培训提醒、跟踪培训状态 |

## 3. 核心流程

质控人员进入系统后，首先通过多维度筛选器定位目标故障群体，在故障热力页掌握整体分布与关键指标；进入案例质量页识别低质量知识条目与不完整案例，评估知识库可靠性；每周复盘时使用复盘清单页，系统自动列出需关注的故障与记录，质控人员逐条分派任务、推动分析与改进，形成质量闭环。

```mermaid

    A["进入看板"] --> B["故障热力页<br/>多维度筛选"]
    B --> C["查看故障分布<br/>与关键指标"]
    C --> D["案例质量页<br/>评估知识可靠性"]
    D --> E["识别低质量条目<br/>与不完整案例"]
    E --> F["复盘清单页<br/>每周质量复盘"]
    F --> G["分派任务<br/>指定工程师"]
    G --> H["补充分析<br/>修订提示"]
    H --> I["发起培训<br/>跟踪改进"]
    I --> J["知识库质量提升"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空蓝 #0F172A 作为背景主色，营造专业、稳重的工业感
- **强调色**：警示橙 #F97316 用于高风险/超时提示，成功绿 #10B981 用于可靠标识，信息蓝 #3B82F6 用于数据高亮
- **中性色**：石板灰系列 #64748B / #94A3B8 / #CBD5E1 用于文本与边框
- **风格定位**：工业数据仪表盘风格，深色主题，高对比度数据呈现，信息密度高但层次清晰
- **布局**：左侧固定导航 + 右侧内容区，顶部筛选器 + 卡片式数据模块
- **字体**：标题使用 JetBrains Mono 等宽字体强化工业感，正文使用 Inter 保证可读性
- **动效**：数据加载渐变、卡片悬停微抬升、筛选切换平滑过渡

| 页面名称 | 模块名称 | UI 元素 |

### 4.3 响应式

- 桌面端优先设计，1440px 基准宽度
- 平板端折叠次要筛选条件为展开面板
- 移动端转为单列堆叠布局，导航改为底部 Tab 栏
